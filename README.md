# Naun Leonan — Personal Portfolio (HTML, CSS & JavaScript)

## Project files
- `index.html`: semantic page structure and content.
- `style.css`: design, CSS variables, responsive layout and dark theme styles.
- `script.js`: theme toggle and automatic current year.

## Run locally
1. Extract this ZIP file.
2. Open the folder in a code editor.
3. Open `index.html` in your browser. You can also use a local development extension such as Live Server.

## Customize before publishing
- Confirm all personal details and certificate dates.
- Replace the GitHub placeholder URL with your actual profile URL.
- Add links to certificates if you have public certificate URLs.
- Add new projects only after you have built and tested them.

## Technologies
HTML5 · CSS3 · CSS custom properties · Flexbox · CSS Grid · Responsive Design · JavaScript DOM events

This is a learning project. Keep improving it and make sure you can explain the code before presenting it as your work.
